# Proof of Execution

Artifacts generated by `./run.sh` on a CUDA-capable machine (e.g. the Coursera
lab):

- **`run_log.txt`** — full console log: detected GPU, single-sort timing
  breakdown, `Verification: PASSED`, and the GPU-vs-CPU benchmark table.
- **`benchmark.csv`** — `size,cpu_ms,gpu_ms,speedup,correct` for six input sizes
  from 4,096 to 4,194,304 elements. This is the experiment's input and output
  data: it shows the code ran on many sizes in a single execution.
- **`sample_input.csv` / `sample_sorted.csv`** — a small, human-readable
  256-element before/after pair committed directly to the repo.

The large `input_<N>.csv` and `sorted_<N>.csv` (the full million-element arrays)
are also produced but git-ignored to keep the repository small.

To package everything for upload:

    zip -r proof.zip proof
